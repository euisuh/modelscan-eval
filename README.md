# modelscan-eval

Meta-benchmark evaluating how well existing ML supply-chain scanners (e.g.
ModelScan, model-file static analyzers) detect malicious/obfuscated Hugging
Face model artifacts (unsafe pickle/torch.load payloads, malicious custom
code, evasion variants) — plus a labeled synthetic corpus for the task.
